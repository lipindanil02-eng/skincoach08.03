# SkinCoach — правила для всех AI-агентов

## Жёсткие запреты
- **НИКОГДА не удалять файлы.** «Не нужно пока» = пропустить в коде, файл оставить.
- **НЕ трогать `best_model.pth`.** Веса ML-модели (124MB), обучались месяц.
- **НЕ трогать работающий код** без крайней нужды. Чини только сломанное.

## Правила кодинга
- `load_dotenv()` всегда ДО импортов из `core.*`, иначе API-ключи пустые.
- `probability` из ML-модели уже 0–100, не умножать на 100 повторно.
- Перед правками объясни проблему простыми словами (1-2 предложения), спроси «можно?».
- Запрещены слова: «нормализую», «контекст», «резолвит», «инъектируется».
- Отвечай на русском, кратко, как живой напарник, а не робот.

## Воркфлоу
1. **План** → объясни что и зачем
2. **Утверждение** → дождись «ок» от Даниила
3. **Код** → реализуй
4. **Тест** → проверь на @Bottestvghh_bot (токен в .env заменить на тестовый)
5. **Пуш** → `git push main master` (только если тест прошёл)
6. **Деплой** → Railway подхватит автоматически

## Структура проекта
```
skincoach/
├── bot.py              # Telegram-бот (python-telegram-bot)
├── core/
│   ├── pipeline.py     # 8-ступенчатый LLM-пайплайн (OpenRouter)
│   ├── config.py       # Все API-ключи и модели из .env
│   └── model_loader.py # Загрузка EfficientNet-B3
├── inference.py        # ML-инференс (EfficientNet-B3, 3 класса)
├── gen_card.py         # Диагностическая карточка (PIL, не Chrome!)
├── web/backend/        # FastAPI бэкенд (не на Railway пока)
├── web/ml_service/     # ML API (не на Railway пока)
└── .env                # Токены (НЕ коммитить!)
```
